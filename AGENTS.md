# AGENTS.md

Before changing this repo, read [PRINCIPLES.md](PRINCIPLES.md) and [code-standards/README.md](code-standards/README.md).
Run `make check` before committing.

Every repo copies `code-standards/README.md` and the topic `.md` files it declares, and its checks fail until it
resyncs whenever one changes. So don't open a PR that changes that text: add a line to [PENDING.md](PENDING.md)
instead, unless you've been asked to ship the change now. Everything else here ships on its own.
